Special commands  
‘E’+’M’+’F’ ‘O’` Full quick cleaning of the emulator memory. Memory  will be filled with 0xFF.  
‘M’+x ‘O’ X: ‘2’ – 28/29F200; ‘4’ – 29F400; ‘8’ – 29F800  Use this command to make sure the emulated memory  
type is correct for proper operation.  
‘M’+’?’ X X: ‘2’ – 28/29F200; ‘4’ – 29F400; ‘8’ – 29F800.   
‘A’+’V’ B1+…+B4 just 4 bytes ACSII number. The value is presented in mV.  Example: 2995 = 2.995V.  
‘l’+x ‘O’ X: ‘H’ – high speed (921600), ‘L’ – low speed (115200).  The function is available only starting from v1.40.  


Software reset 
	‘Q’ 
	- 
	Simply restarting the emulator is equivalent to turning  off the power. 
	



Additional notes:  
1. FlashOnline have 1024k memory (or 512x16) organization, to write files 256k (28 / 29F200)  MMSB must be 0x0C, for 512k (29F400) it is 0x08, for 1024k (29F800) it is 0x0, respectively.  2. CS – is Check Sum. Are just 8-bit additive of the rest of the request, no carry.
